# BB(6) reductions

Proved reductions of BB(6) holdouts to simpler questions. **These settle no machine.** Each one turns "does this machine halt" into an exact, machine-free statement, so an answer to that statement settles every machine it covers.

| Folder | Machines | Reduction |
|---|---|---|
| [`g16/`](g16/README.md) | 16 holdouts | Each halts iff some stack of one explicit orbit has a top event with P + 2 a power of 2 |
